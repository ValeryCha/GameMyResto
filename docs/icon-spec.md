# Спецификация иконок интерфейса

## 1. Принципы

Иконки решают существующие задачи интерфейса и не копируют графику, брендинг или персонажей референса. Назначение кнопки всегда дублируется доступным именем; непонятные пиктограммы из видео не добавляются.

Основа — существующий генератор `createIcon` из `src/ui/icons.ts`:

- inline-SVG с `viewBox="0 0 24 24"`;
- `fill="none"`, `stroke="currentColor"`;
- `stroke-width="1.8"`, `stroke-linecap="round"`, `stroke-linejoin="round"`;
- `aria-hidden="true"` и `focusable="false"`;
- цвет наследуется от кнопки, поэтому состояния не требуют отдельных SVG;
- геометрия должна оставаться внутри viewBox, оптические отступы — примерно 2–3 единицы;
- простые формы, одинаковая визуальная плотность, без мелких деталей, исчезающих при 24 px.

`setButtonIcon(button, label, icon)` уже создаёт скрытый текст `.sr-only`, `aria-label` и `title`. Новые вызовы должны использовать тот же путь вместо SVG с самостоятельным `aria-label`, чтобы не дублировать имя.

## 2. Размеры и доступность

| Контекст | SVG | Интерактивная цель | Требование |
|---|---:|---:|---|
| Нижняя навигация | 25–29 px | не менее 44×44 CSS px | Сохранить текущие имена и `title`. |
| Категории магазина | 24–27 px | не менее 44×44 CSS px | `role="tab"`, `aria-selected`, видимый фокус. |
| Карточка предмета | 50–58 px | вся карточка | SVG декоративно; имя карточки включает предмет и статус. |
| Кнопки редактора и закрытия | 24–25 px | не менее 44×44 CSS px | Disabled обозначается состоянием кнопки, не только прозрачностью. |
| Камера | 22–24 px | не менее 44×44 CSS px | Текущие aria-имена обязательны. |
| Стрелки возможной пагинации | 22–24 px | не менее 44×44 CSS px | Доступные имена содержат «магазина», чтобы не путать с камерой и прокруткой категорий. |

Не использовать эмодзи, текстовые символы и изображения референса как замену SVG. Не кодировать смысл только цветом: активность дополняется `aria-selected`/текстом, блокировка — `disabled` и статусом.

## 4. Сопоставление с референсом

| Видимый элемент | Решение для нашего UI | Имя |
|---|---|---|
| Категории каталога | Сохранить наши шесть категорий и девять подкатегорий декораций. Не реконструировать чужие силуэты. | Существующие `kitchen`, `hall`, `staff`, `recipe`, `decor`, `rating`, `wallpaper`, `floor`, `door`, `table`, `chair`, `window`. |
| Карточки предметов | Специальные превью остаются приоритетными; общий SVG используется при его отсутствии. | Существующие `item.icon`, `createShopThumbnail`, `createDishIcon`. |
| Поворот | Использовать текущую иконку, не добавлять второй вариант. | `rotate`. |
| Подтверждение режима | Использовать текущую галочку только для существующего завершения режима. | `check`. |
| Возврат к стандартному виду | Использовать текущий сброс. | `reset`. |
| Стрелки каталога | Только если выбрана пагинация в Фазе 1 P3. Для неё нужны отдельные однонаправленные chevron-иконки, а не `back`, `move` или `rotate`. | Новые `chevronLeft`, `chevronRight` — кандидаты. |
| Камера | Заменить текстовые символы согласованными SVG, если подтверждён соответствующий пункт P2. | Новые `zoomIn`, `zoomOut`, `home` — кандидаты. |

## 5. Допустимые новые имена и геометрия

Новые имена добавляются только при реализации соответствующего согласованного пункта. До этого они не считаются доступными.

| Кандидат | Геометрия в сетке 24×24 | Доступное имя кнопки | Комментарий |
|---|---|---|---|
| `chevronLeft` | Одна ломаная от `(15,5)` через `(8,12)` к `(15,19)`. | «Предыдущая страница магазина» | Без дополнительной горизонтальной линии, чтобы отличаться от `back`. |
| `chevronRight` | Зеркально: от `(9,5)` через `(16,12)` к `(9,19)`. | «Следующая страница магазина» | Disabled на последнем краю. |
| `zoomIn` | Круг увеличительного стекла, ручка и внутренний плюс; все элементы внутри `(3…21)`. | «Приблизить камеру» | Сохраняет текущее действие. |
| `zoomOut` | Та же форма с внутренним минусом. | «Отдалить камеру» | Сохраняет текущее действие. |
| `home` | Контур дома без надписи и без дополнительного смысла «главное меню». | «Сбросить вид» | Только для сброса камеры; имя не менять на «Домой». |

## 6. Состояния и повторное использование

- **Обычное:** `currentColor`, без отдельного цвета в разметке.
- **Hover/focus:** меняется фон, рамка или положение кнопки, а не структура SVG.
- **Selected:** существующие классы `is-active`; у категории также `aria-selected="true"`.
- **Disabled:** нативный `disabled`, читаемый статус; иконка не превращается в единственный признак недоступности.
- **Locked:** существующий `lock`; цена/требуемый уровень остаются в карточке.
- **Owned/active:** текстовый статус и `is-active`; новые галочки поверх превью не требуются.
- **Reduced motion:** иконки не вращаются, не пульсируют и не масштабируются; состояние остаётся видимым.

## 7. Приёмка иконок

1. Все имена принадлежат `IconName`; TypeScript не допускает произвольных строк.
2. SVG наследует цвет и остаётся различимым при 24 px.
3. Каждая icon-only кнопка имеет уникальное в своём контексте `aria-label` и `title`.
4. Фокус клавиатуры видим, Enter/Space вызывают прежнее действие.
5. При ширине 360 px и масштабировании текста цели не перекрываются.
6. Ни одна новая иконка не добавляет игровую функцию и не меняет сохранение.
