# Главное меню «Мой ресторан»

## Цель

Добавить главное меню и переходы между ним и существующей 3D-игрой, не переписывая симуляцию, модели и формат сохранения. Всё остаётся одной локальной SPA-страницей без внешних ассетов.

## Экраны

- **Главное меню:** логотип «Мой ресторан», собственный декоративный фасад из CSS/SVG, текущий баланс и кнопки «Играть», «Новая игра», «Настройки», «Об игре».
- **Игра:** существующие 3D-зал и HUD плюс кнопка «Меню».
- **Настройки:** переключатель «Звук» с пояснением, что звуковое сопровождение появится позже; значение хранится отдельным ключом `moy-restoran:sound`.
- **Об игре:** короткое описание цели и управления.

## Переходы и состояние

При загрузке показывается меню, 3D-мир ещё не запускается. «Играть» создаёт мир из `storage.load()` или продолжает уже созданный мир после возврата. Кнопка «Меню» сохраняет текущее состояние, останавливает animation loop и открывает меню с обновлённым балансом.

«Новая игра» открывает подтверждение с явным предупреждением об удалении прогресса. Только подтверждение вызывает `storage.reset()`, создаёт `createGame()`, сохраняет его и заменяет текущий мир новым. Отмена ничего не меняет. Старые ресурсы мира освобождаются при замене; повторный вход не создаёт второй animation loop.

## Архитектура файлов

- `src/ui/mainMenu.ts` — создание четырёх экранов, кнопки и callbacks.
- `src/ui/styles.css` — адаптивное оформление меню, панелей, диалогов и кнопок.
- `src/persistence/storage.ts` и `localStorageAdapter.ts` — добавить `reset(): void`, сохранив прежние ключи и envelope.
- `src/render3d/RestaurantWorld.ts` — безопасные `start()`, `stop()` и `dispose()`.
- `src/main.ts` — координация меню, активного состояния, мира и сохранений.

## Визуальный стиль и доступность

Кремовые панели, терракотовые и зелёные кнопки, тёмно-коричневый текст, крупные читаемые названия и заметный keyboard focus. Меню помещается при 390×844 без горизонтальной прокрутки. Диалоги используют кнопки с понятными названиями; скрытые экраны недоступны навигации. Нет внешних шрифтов, изображений, платных ресурсов или выдуманного работающего звука.

## Ошибки и границы

Ошибка WebGL по-прежнему показывает русское сообщение, а меню остаётся доступным. Отсутствие сохранения показывает начальный баланс 1000. Сброс удаляет primary и backup. Магазин скинов, настоящая музыка, аккаунты и социальные функции не входят в этап.

## Проверка

- Unit: `reset()` удаляет оба ключа; следующий `load()` возвращает 1000 монет.
- Browser: меню → «Играть» → гость и 3D-зал → покупка → «Меню» → баланс 950 → «Играть» → сохранённая покупка.
- Browser: «Новая игра» → отмена сохраняет баланс; повторный вызов → подтверждение возвращает 1000.
- Browser: настройки переключаются и сохраняются; «Об игре» открывается и закрывается; все кнопки доступны.
- Снимки меню и игры на desktop/mobile, визуальный просмотр и исправление обнаруженного дефекта.
- `npm test`, `npm run build`, `npm run test:e2e` проходят без console/page/HTTP errors; dev server после проверки остановлен.
