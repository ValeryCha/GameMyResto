# Перемещение камеры

## Цель

Добавить свободное, но ограниченное границами ресторана перемещение камеры мышью, касанием и клавиатурой без конфликтов с размещением и редактором мебели.

## Управление

- Перетаскивание левой кнопкой мыши или одним пальцем по пустой 3D-сцене сдвигает камеру вслед за указателем.
- `WASD` и стрелки перемещают камеру в соответствующем экранном направлении. Клавиши игнорируются при фокусе в поле ввода и при открытом главном меню.
- Кнопка «Сбросить вид» рядом с зумом возвращает исходное положение и масштаб 1.
- Режимы размещения, переноса двери, перемещения мебели и редактирования отключают drag-панорамирование. Существующие клики по сцене и объектам сохраняют поведение.

## Реализация

`RestaurantWorld` хранит смещение центра вида `pan` в мировых координатах. `resize()` вычисляет исходный центр от размеров поля, затем применяет `pan`; зум не сбрасывает смещение. Скорость перетаскивания учитывает текущий зум и размеры canvas.

Смещение ограничено областью ресторана с небольшим внешним запасом: его нельзя бесконечно увести за пределы сцены. При расширении поля допустимые границы пересчитываются, существующий вид сохраняется по возможности.

Pointer capture используется на время перетаскивания. `pointerup`, `pointercancel`, выход в меню и `dispose()` завершают жест и удаляют слушатели. Кнопки камеры не передают события сцене.

Формат сохранения игры не меняется: положение камеры является временным состоянием представления, не частью `GameState`.

## Проверка

- Browser: drag меняет вид без выбора/покупки мебели, `WASD` и стрелки работают, сброс восстанавливает вид.
- Mobile 390×844: касание перемещает камеру, кнопки зума и сброса остаются доступны, магазин прокручивается независимо.
- Размещение и редактор проходят существующие E2E без регрессий.
- Полные `npm test`, `npm run build`, `npm run test:e2e` и визуальные снимки; временный сервер после проверки останавливается.
