# Спецификация анимаций v2

## Наследование v1

Токены `docs/animation-spec.md` сохраняются: отклик 120–140 мс, выбор 160–180 мс, открытие панели 200 мс, закрытие 160 мс; появление `cubic-bezier(0.2,0,0,1)`, скрытие `cubic-bezier(0.4,0,1,1)`, состояния `ease-out`. Новые скриншоты не содержат оснований для изменения этих значений и не подтверждают параметры анимаций оригинала.

Команды выполняются в обработчиках, не по `transitionend`/`animationend`. Не анимируются числа `GameState`, гости, сотрудники и камера. Range камеры синхронизирует значение без декоративного tween. Игровая пошаговая логика, throttling обновлений и интерполяция движения в 3D остаются отдельными от CSS-переходов; полная перестройка UI каждый кадр запрещена.

## Состояние пагинации

1. Сначала вычисляется отфильтрованный список; только затем размер страницы и диапазон видимых карточек.
2. Размер страницы соответствует фактическим CSS-breakpoints: 10/6/4 элемента. Не допускать расхождения, при котором стрелка скрывает заполненный CSS-ряд.
3. `click` по стрелке синхронно меняет runtime-номер страницы и видимость; визуальный переход не хранит второй номер страницы.
4. Поиск, категория и подкатегория сбрасывают страницу на первую. `update(state)` не сбрасывает её, а только ограничивает допустимым диапазоном.
5. Disabled вычисляется после каждого изменения списка. При одной странице обе стрелки недоступны.
6. Номер страницы, transition-классы и бейджи не записываются в `GameState` и файлы сохранений.

## Правила прерывания и производительности

- При быстрой смене страницы предыдущий CSS-transition отменяется новым состоянием тех же элементов; не создавать клоны сетки и очередь анимаций.
- Во время закрытия магазина стрелки и карточки сразу неинтерактивны.
- Не скрывать карточки с задержкой ради завершения движения: это создаёт расхождение доступного и видимого состояния.
- Обновления `GameState` изменяют только значения и классы затронутых элементов. Существующий ключ иконки предотвращает лишнее пересоздание SVG и должен сохраниться.
- Не анимировать layout-свойства и не запускать `requestAnimationFrame` ради пагинации, бейджей или полосы опыта.
- Range камеры не должен вызывать сохранение, пересчёт экономики или анимационный цикл; он использует существующий `resize()` и ограничения зума.

## Приёмка

| Сценарий | Ожидаемый результат |
|---|---|
| Быстро нажать «Следующая страница магазина» до последнего края | Показана последняя допустимая страница, стрелка disabled, нет пустого экрана и очереди промежуточных переходов |
| Изменить поиск на странице выше первой | Показана первая страница отфильтрованного списка, обе стрелки корректно обновлены |
| Переключить категорию во время перехода | Активна только последняя категория, первая её страница, прежние карточки не кликабельны |
| Открыть и закрыть магазин повторно | Slide не накапливается, панель не перехватывает клики после закрытия |
| Получить доступную награду календаря | Бейдж отражает состояние без пульсации; имя кнопки не меняется |
| Изменить масштаб кнопкой, колесом, range и сбросом | Все способы синхронизированы, границы сохранены, нет цикла событий |
| Включить reduced-motion | Нет slide, translate и scale; категории, страницы и камера работают мгновенно |
| Ширина 360/768/1280 px | Переходы не меняют размеры сетки и не создают переполнение; тач-цели остаются доступными |
