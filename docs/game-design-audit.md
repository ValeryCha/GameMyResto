# Аудит связности игровых систем — финальная редакция

Проект: «Мой ресторан». Документ описывает целевые связи без реализации кода.

## 1. Инварианты

- Уровни 1–33; рейтинг переводится со шкалы 0–100 на 0–1000 без изменения относительной сложности.
- Не более 5 официантов, 5 стоек, 3 поваров и 3 плит. Кухня: тир 1 — старт, тир 2 — уровень 15 (повар 15,000 + плита 20,000), тир 3 — уровень 25 (повар 35,000 + плита 50,000). Полный комплект 3/3 — 121,200 монет, +84 рейтинга.
- Текущая кухня 1 повар / 1 плита валидна; отсутствие объекта означает нулевое звено.
- Детерминированное `waiterIndex % counters.length` сохраняется с коэффициентом `D = 0.92`.
- Суммарный бонус скинов кухни ограничен +5% скорости.
- Существующее терпение гостя за столиком не меняется. Новый таймер относится только к очереди.
- Поведение `notify` остаётся заменой сообщения, а не стеком.
- Формат состояния переводится на `version: 2` с однократной миграцией.

|---|---|---|---|---------------------------------------------|

| Расширение | Пространство для мест и маршрутов | +2 к размерам, рейтинг, автообои | Площадь сама не даёт оборот | Показ лимитирующего звена                   |

## 3. Главные разрывы

1. Купленные слоты теряют эффект на высоком уровне.
2. Один повар и одна плита ограничивают пять официантов.
3. Пик не имеет измеримого результата и награды.
4. Нет очереди как читаемого сигнала перегрузки.
5. Декор и задания слабо связаны с развитием.
6. HUD показывает лимит, но не его причину.
7. Шкала рейтинга 0–100 недостаточно гранулярна для новых штрафов и наград.

## 4. Приоритет внедрения

1. Аудит и фиксация формул.
2. Пик и его статистика.
3. Очередь и причины ухода.
4. `capacity / arrivalRate / throughput` с капом спроса.
5. Задания и baseline.
6. HUD и шкала рейтинга 0–1000.
7. LOGIC-7: найм поваров и покупка плит до 3/3 (тир 2 на 15 ур., тир 3 на 25).

Миграция `version: 2` должна предшествовать включению новых формул, чтобы старые значения рейтинга не были дважды масштабированы.

## 6. Риски

| Риск | Последствие | Ограничение |
|---|---|---|
| Чрезмерный спрос | Рейтинг падает от 1000 до 0 за один пик | `arrivalRate ≤ throughput × 1.3` |
| Слоты снова бесполезны | Плата без эффекта | Каждый слот участвует в `slotDemand` до общего капа |
| Двойная миграция рейтинга | 47 превращается в 4700 | Однократный переход версии 1→2 |
| Регресс старых сейвов | Потеря прогресса | Дефолты `normalizeState`, baseline текущих счётчиков |
| Перегрузка симуляции | Дорогие пересчёты | Метрики на игровом тике, не на рендер-кадре |
| Скины обходят прокачку | Нарушение экономики | Общий кап +5% |
| Завышенный оборот | Неверные ожидания | `D = 0.92` |
| Бесплатные награды | Экономическая инфляция | Побочные задания от сохранённого `questBaseline` |
| Слишком слабые декорные награды | Покупка окупается заданием | `reward ≤ Σ(price) × 0.8` |
